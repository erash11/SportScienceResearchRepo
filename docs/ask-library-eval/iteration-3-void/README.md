# Iteration 3 (void run)

Drafter v1.2 (critic pass) was run on all 12 questions, but verification used only `pdftotext -layout` text. These briefs were not audited. The fix (verify against both layout and reading-order text) was applied and iteration 3 was re-run; see `iteration-3/`.
