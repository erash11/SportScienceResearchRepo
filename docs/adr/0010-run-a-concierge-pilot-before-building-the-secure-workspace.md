# Run a concierge pilot before building the secure Ask the Library Workspace

The first real-world evaluation will be a two-week, operator-mediated concierge pilot rather than an authenticated self-service deployment. Three staff from at least two functions will submit nine de-identified Practical Questions; an operator will prepare each Decision Brief through the approved interface, and every claim and citation will be audited before delivery.

This preserves the confirmed Decision Brief and evidence-integrity contract while deferring authentication, private cloud storage, retrieval infrastructure, and model procurement until staff utility is demonstrated. The concierge workflow is not the production Ask the Library Workspace, does not test response latency or self-service adoption, and must not be presented as automated or expert-reviewed.

If the confirmed expansion gates pass, the next technical decision will select a secure staff-only platform. The leading candidate is a separate Azure-hosted workspace with single-tenant Microsoft Entra authentication; the public GitHub Pages Evidence Library remains unchanged.
