# Reviewed Zotero publications

This directory contains reviewer-approved, versioned publication records created from validated Zotero Paper
Brief candidates.

- `STAGED` records reserve the next unused stable Evidence Library ID across published and staged records but
  are not present in `papers.json`.
- `PUBLISHED` records must match `papers.json`, `paper-taxonomy.json`, and the Zotero publication audit.
- A record preserves Zotero item/version identity, Paper Brief hash, Evidence Locator pages, accountable reviewer,
  public synthesis, and reviewed taxonomy.

Never place Zotero PDFs, credentials, private notes, or participant data here.
